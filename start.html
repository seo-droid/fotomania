나도 FotoMania 시작하기

내 구글 계정에 나만의 FotoMania를 만들어요. 처음 한 번, 약 5분이면 돼요.
사진은 내 구글 드라이브에 저장되고, 비용은 없어요.

준비물: 구글 계정 하나 · 컴퓨터(처음 설정은 PC가 편해요) · 그 뒤로는 휴대폰으로도 다 돼요

  1. FotoMania 복사하기

    아래 버튼을 누르면 내 구글 드라이브에 FotoMania 시트(앱 포함)가 복사돼요. 「사본 만들기」를 누르세요.

    📋 내 드라이브에 복사
    복사용 시트를 준비하고 있어요. 조금만 기다려 주세요 🙏 (FotoMania를 알려 준 분께 링크를 부탁해도 돼요)

  2. 웹 앱으로 배포하기

    복사한 시트에서 확장 프로그램 → Apps Script를 열고, 오른쪽 위 배포 → 새 배포를 눌러요.

    • ⚙ 유형 선택 → 웹 앱
    • 실행 계정: 나 · 액세스 권한: 모든 사용자 → 배포
    • 권한 창이 뜨면 내 계정 선택 → 「확인되지 않은 앱」이 나오면 고급 → (프로젝트)로 이동 → 허용
    • 나온 웹 앱 URL(…/exec 로 끝나요)을 복사해요
    「확인되지 않은 앱」은 내가 방금 복사한 내 앱이라서 나오는 안내예요. 내 드라이브·시트에만 접근해요.

  3. 처음 설정

    시트로 돌아가 새로고침하면 위에 📸 FotoMania 메뉴가 생겨요. 📸 FotoMania → 처음 설정을 누르고 복사한 웹 앱 주소를 붙여 넣어요.

  4. 내 사진 앱 열기

    📸 FotoMania → 📱 내 사진 앱 열기에서 나온 링크가 나만 쓰는 사진 앱이에요. 이 링크는 남에게 보내지 마세요.

  5. 휴대폰에 설치하기

    휴대폰에서 FotoMania 앱 화면을 열고 위 링크를 한 번 붙여 넣은 다음, 홈 화면에 추가해요.

    • 아이폰: 사파리 아래 공유(□↑) → 홈 화면에 추가
    • 안드로이드: 크롬 ⋮ → 앱 설치
다 됐어요! 사진을 올리고 앨범에서 💌 공유하기를 눌러 보세요.
